# Student Dashboard Hub

A fully responsive Next.js front-end web application dashboard built as a specialized project assignment for Internshala.

## 🚀 Live Demo
You can view the fully hosted live application here: 
https://student-dashboard-nu-peach.vercel.app/

## 🛠️ Features & Tech Stack
- **Framework:** Next.js (React)
- **Database Connection:** Supabase (PostgreSQL) Live Integration
- **Styling:** Responsive Modern Dashboard Panels (Sidebar navigation, Analytics charts, Schedule tracking)
- **Variables:** Configured securely via live cloud Environment Variables
